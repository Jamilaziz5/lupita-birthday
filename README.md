# Java Birthday Lookup

A simple Java application developed for my Intro to Java course that allows users to look up birthdays by entering a person's name.

## Features

- Reads birthday information from a JSON file
- Stores names and birthdays using a Java HashMap
- Accepts user input to search for a person's birthday
- Displays the matching birthday if found
- Displays "Birthday unknown" if the name isn't found

## Technologies Used

- Java
- HashMap
- JSON / JSON.simple
- Maven

## About the Project

This assignment helped me practice working with HashMaps, user input, and retrieving information from stored data.

The project used instructor-provided starter code for JSON parsing and HashMap initialization. I implemented the interactive birthday lookup functionality.
